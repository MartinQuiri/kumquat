# Código de conducta

Kumquat adopta el **[Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)** como código de conducta para todos los espacios del proyecto (issues, PRs, discusiones).

En resumen: trato respetuoso, crítica al código y no a las personas, cero acoso.

Para reportar un comportamiento inaceptable, escribe a las personas mantenedoras usando el contacto privado del perfil de GitHub del repositorio. Los reportes se tratan con confidencialidad.
